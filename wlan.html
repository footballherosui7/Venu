1. Auf diesem PC

Öffne das Spiel, wähle Multiplayer und erstelle einen Raum. Lass das schwarze Serverfenster geöffnet.

Spiel öffnen

2. Freunde verbinden

Deine Freunde öffnen eine dieser Adressen in ihrem Browser. Danach geben sie unter Multiplayer deinen Raumcode ein. Sie benötigen keine Installation.

localhost funktioniert nur auf dem PC, auf dem der Server läuft.

Die Adresse geht beim Freund nicht?

Beide Geräte müssen im selben Heimnetz sein. Ein Gastnetz kann Geräte voneinander trennen. Prüfe die richtige Adresse bei mehreren Netzwerkadaptern.

Wenn Windows die Verbindung blockiert: Stelle dein eigenes Heimnetz als privates Netzwerk ein und führe WLAN_Freigeben.bat per Rechtsklick als Administrator aus. Sie erlaubt ausschließlich TCP 8088 aus dem lokalen Subnetz im privaten Netzwerk.

Die Firewall muss dafür nicht ausgeschaltet werden. WLAN_Freigabe_entfernen.bat nimmt diese Freigabe wieder zurück.
